### Репозитории

- **[mcp-weather-connector](https://github.com/KDimkuz/mcp-weather-connector)** — MCP-сервер, дающий ИИ-агенту доступ к внешнему API. Инструментальный слой с валидацией входа и ограничением набора действий.
- **[llm-guard](https://github.com/KDimkuz/llm-guard)** — обвязка вокруг LLM API: структурированный вывод со схемой, валидация ответа, ретраи, бюджет токенов, фолбэк на человека.
- **[platform-image-generator](https://github.com/KDimkuz/platform-image-generator)** — генератор изображений под требования площадок: сторис 1080×1920, обложки Дзена и ВК с учётом зон обрезки.

### Рабочие проекты

Код клиентских систем закрыт, но вот что построено и работает:

- **ИИ-продавец для салона** — ассистент на связке сервиса онлайн-записи и amoCRM: приём и квалификация обращений, запись, передача менеджеру. Отдельный сценарий находит окна в расписании и дозаписывает клиентов из базы. Работа с закрытым API без документации: логику авторизации восстанавливал через разбор трафика.
- **Creator** — PWA, которая проводит интервью, собирает бренд-профиль и генерирует по нему контент. FastAPI, очередь на arq + Redis, отдельный воркер под рендер видео на ffmpeg.
- **LeadAnalyzer** — дашборд входящих обращений со скорингом готовности к покупке. Flask, продакшн-деплой из git.
- **[кдмаркетинг.рф](https://кдмаркетинг.рф)** — сайт практики. Next.js, Serverless Containers за API Gateway в Yandex Cloud.
